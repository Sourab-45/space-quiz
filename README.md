# Orbit Quiz

Orbit Quiz is a standalone space exploration quiz with ten questions, animated answer feedback, score tracking, and a results screen. It is built with HTML, CSS, and vanilla JavaScript and has no runtime dependencies.

## Run locally

Open `index.html` directly in a modern web browser. No server, package manager, or build step is required.

## Deployment

GitHub Actions publishes the static site to GitHub Pages whenever changes are pushed to the `sourab-45-space-quiz` branch. The workflow packages `index.html` as the site artifact and deploys it using the GitHub Pages actions.
